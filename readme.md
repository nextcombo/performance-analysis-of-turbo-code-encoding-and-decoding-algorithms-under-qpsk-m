The purpose of channel coding is to enhance the reliability of data transmission over noisy channels. Channel coding adds redundant information to the encoded sequence after source encoding, thereby improving the reliability of transmission. The Shannon channel coding theorem states that there exists an appropriate channel coding scheme when the channel's transmission rate does not exceed its capacity, which can achieve error-free transmission.
In 1993, parallel convolutional codes, also known as turbo codes, were proposed. At the encoding end, it employs a cascade of encoders with interleavers, and at the receiving end, it uses the maximum a posteriori probability algorithm for iterative decoding. Turbo codes break away from the design concept of minimum distance code, closer to Shannon's concept of random codes; they also utilize a novel iterative decoding approach, thus truly tapping into the potential of cascade codes, leading to a bit error rate performance that approaches the Shannon limit. In third-generation mobile communication systems, turbo codes are adopted as their channel coding standard for transmitting high-speed data.
This article first provides a detailed introduction to the turbo code's encoding and decoding technologies, including the interleaver in the encoder and the iterative decoding structure.

Turbo code differs from traditional serial concatenation coding models in that it consists of two recursive system convolutional (RSC) encoders connected in parallel through an interleaver, hence its name is Parallel Concatenated Convolutional Code (PCCC). The basic structure of a Turbo code encoder is shown in the figure. Turbo codes are constructed by parallel concatenating component codes through a random interleaver, resulting in long codes with pseudorandom properties. After the information sequence U undergoes the first component encoder, it generates parity information sequence X1p. The interleaved bits enter the second component encoder to produce parity information sequence X2p. The information sequence is directly outputted to produce the system information sequence Xs. This combined sequence is adjusted and matched by a redundancy remover before being input into the channel for encoding. The interleaver, as an essential component in the Turbo code encoding structure, is responsible for rearranging the received packet bits pseudo-randomly before they are encoded by the second encoder. Prior to the introduction of the Turbo code encoding scheme, interleavers had been widely used in wireless communication systems to combat burst errors in Rayleigh fading channels. Typically located between the encoder and the channel, the interleaver rearranges the order of the information sequence to be transmitted. Similarly to the transmitter, the deinterleaver is situated between the receiving end's channel and the decoder. When both interleavers and deinterleavers are used together, it effectively disperses clustered burst errors into random errors. There are various types of interleavers, including row interleavers, stacked interleavers, QPP (Quasi-Pseudo-Random) interleavers, pseudo-random interleavers, and group spiral interleavers, among others. The choice of interleaver type often depends on the specific application scenario. Interleavers can influence the performance of Turbo codes; as the length of the interleaver increases, so does the performance of the Turbo code but also the decoding delay.

In actual communication systems, through the deletion of redundant information, higher channel coding code rates can be obtained.
Turbo Code Decoding Algorithm
The Turbo code uses two component encoders and an interleaver as its coding structure, so correspondingly, the decoder also includes two component decoders, in addition, there are also interleavers and deinterleavers between the decoders, which perform interleaving and de-interleaving operations on the received information, so that the corresponding information can be transmitted between the two component decoders until the last iteration output. It should be noted that the structure and parameters of the interleavers and deinterleavers in the decoder should be the same as those in the encoder.
